## Code blocks

Fenced code blocks are syntax-highlighted (Shiki), with a title, a copy button,
and line highlighting — no setup required.

```ts title="lib/measure.ts" {3-4}
import { prepare, layout } from '@chenglou/pretext';

const prepared = prepare(text, '16px Inter');
const { lineCount, height } = layout(prepared, 640, 32);

console.log(lineCount, height);
```

## Code tabs

Group related snippets into tabs — great for showing the same thing in multiple
languages or frameworks.

<Tabs items={['TypeScript', 'JavaScript']}>

```ts tab="TypeScript"
export function greet(name: string): string {
  return `Hello, ${name}`;
}
```

```js tab="JavaScript"
export function greet(name) {
  return `Hello, ${name}`;
}
```

</Tabs>

## Package-manager tabs

A single `package-install` block becomes npm / pnpm / yarn / bun tabs, and the
manager you pick is remembered across the whole site.

```package-install
@chenglou/pretext
```
